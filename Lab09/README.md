## 1. Experiment Title
Tables with Headers and Footers

## 2. Aim
To create an HTML table using table headers, body and footer sections.

## 3. Software / Tools Required
- HTML
- Visual Studio Code
- Web Browser

## 4. Theory
HTML tables organize information into rows and columns. The `table` element creates a table, `tr` defines a row, `th` defines a header cell and `td` defines a data cell. The `thead`, `tbody` and `tfoot` elements group table sections. The `colspan` attribute allows a cell to span multiple columns.

## 5. Algorithm / Procedure
1. Create an HTML document.
2. Add a table element.
3. Create the table header using `thead`.
4. Add data rows inside `tbody`.
5. Add a footer using `tfoot`.
6. Use `colspan` wherever required.
7. Open the webpage in a browser.
