## 1. Experiment Title
Sign-Up Forms and Choices

## 2. Aim
To create a student registration form using HTML form elements.

## 3. Software / Tools Required
- HTML
- Visual Studio Code
- Web Browser

## 4. Theory
HTML forms collect information from users. The `form` element contains controls such as text inputs, radio buttons, checkboxes, dropdown lists and submit buttons.

## 5. Algorithm / Procedure
1. Create an HTML document.
2. Add a form element.
3. Insert input fields for user details.
4. Add radio buttons and checkboxes.
5. Create a dropdown menu.
6. Add a submit button.
7. Open the form in a browser and test its controls.
