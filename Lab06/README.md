## 1. Experiment Title
Types of HTML Lists

## 2. Aim
To learn and implement different types of lists in HTML.

## 3. Software / Tools Required
- HTML
- Visual Studio Code
- Web Browser

## 4. Theory
HTML provides three main types of lists. Ordered lists (`ol`) display numbered items, unordered lists (`ul`) display bulleted items, and description lists (`dl`) display terms with their descriptions.

## 5. Algorithm / Procedure
1. Create an HTML document.
2. Add an ordered list using `ol`.
3. Insert list items using `li`.
4. Add an unordered list using `ul`.
5. Create a description list using `dl`, `dt` and `dd`.
6. Save and open the webpage in a browser.

Refer to the existing `index.html` file for the complete HTML source code.

List items, terms and descriptions.
