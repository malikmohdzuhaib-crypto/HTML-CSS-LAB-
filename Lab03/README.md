# EXPERIMENT NO. 03

## 1. Experiment Title
Your First HTML Page

## 2. Aim
To create a basic webpage using HTML elements.

## 3. Software / Tools Required
- HTML
- Visual Studio Code
- Web Browser

## 4. Theory
HTML (HyperText Markup Language) is used to structure webpages. A basic HTML document contains elements such as `html`, `head`, `title` and `body`. Headings and paragraphs are used to display textual content.

## 5. Algorithm / Procedure
1. Open Visual Studio Code.
2. Create an HTML file.
3. Write the basic HTML document structure.
4. Add a page title.
5. Insert headings and paragraphs in the body.
6. Save the file with the `.html` extension.
7. Open it in a web browser.

## 6. Program / Queries / Commands
Refer to the existing `index.html` file for the complete HTML source code.

## 7. Input
HTML elements and text content entered in the HTML file.

## 8. Output
A simple webpage displaying headings and paragraphs.
