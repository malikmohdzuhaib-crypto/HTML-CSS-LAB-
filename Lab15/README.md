## 1. Experiment Title
Responsive Pages with Media Queries

## 2. Aim
To create a responsive webpage using CSS media queries.

## 3. Software / Tools Required
- HTML
- CSS
- Visual Studio Code
- Web Browser
- Browser Developer Tools

## 4. Theory
Responsive web design allows webpages to adapt to different screen sizes and devices. CSS media queries apply styles based on conditions such as viewport width. Flexible layouts and suitable breakpoints help make webpages usable on mobile and desktop screens.

## 5. Algorithm / Procedure
1. Create an HTML document.
2. Create and link an external CSS file.
3. Design the basic webpage layout.
4. Add the viewport meta tag.
5. Define suitable CSS media queries.
6. Adjust layout and styling for different screen widths.
7. Test the webpage using browser resizing or Developer Tools.

Refer to the existing `index.html` and `style.css` files for the complete source code.

## 7. Input
Webpage content and viewport sizes for testing.
