## 1. Experiment Title
CSS Fundamentals

## 2. Aim
To understand and apply basic CSS properties to style an HTML webpage.

## 3. Software / Tools Required
- HTML
- CSS
- Visual Studio Code
- Web Browser

## 4. Theory
CSS (Cascading Style Sheets) is used to control the presentation of HTML documents. It provides properties for colors, backgrounds, fonts, text alignment, margins, padding and borders.

## 5. Algorithm / Procedure
1. Create an HTML document.
2. Create an external CSS file.
3. Link the CSS file to the HTML document.
4. Apply colors and background properties.
5. Set font size and text alignment.
6. Apply margins, padding and borders.
7. Open the webpage in a browser.

## 6. Program / Queries / Commands
Refer to the existing `index.html` and `style.css` files for the complete source code.

## 7. Input
HTML content and CSS property values.

## 8. Output
A styled webpage demonstrating basic CSS properties.
