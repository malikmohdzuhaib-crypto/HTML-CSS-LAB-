# EXPERIMENT NO. 01

## 1. Experiment Title
Starting a Git Repository

## 2. Aim
To learn how to create and manage a Git repository using basic Git commands.

## 3. Software / Tools Required
- Git
- Git Bash / Command Prompt
- Visual Studio Code
- GitHub

## 4. Theory
Git is a distributed version control system used to track changes in files and manage source code. It allows developers to initialize repositories, stage files, commit changes and check repository status.

**Concepts:**
- Git initialization
- Adding files
- Committing changes
- Checking repository status

## 5. Algorithm / Procedure
1. Install Git on the system.
2. Open Command Prompt or Git Bash.
3. Navigate to the project directory.
4. Initialize a Git repository using `git init`.
5. Add project files using `git add .`.
6. Commit changes using `git commit`.
7. Check repository status using `git status`.

## 6. Program / Queries / Commands
```bash
git init
git add .
git commit -m "First commit"
git status
```

## 7. Input
Project files and folders created in the working directory.

## 8. Output
A webpage displaying basic Git commands.

Successfully learned how to initialize a Git repository, add files, commit changes and check repository status using basic Git commands.
