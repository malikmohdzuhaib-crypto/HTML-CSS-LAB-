# EXPERIMENT NO. 05

## 1. Experiment Title
Links and Images

## 2. Aim
To learn how to insert hyperlinks and images into an HTML webpage.

## 3. Software / Tools Required
- HTML
- Visual Studio Code
- Web Browser
- Image file

## 4. Theory
The HTML anchor (`a`) element creates hyperlinks using the `href` attribute. The image (`img`) element displays images using the `src` attribute. The `alt` attribute provides alternative text for an image.

## 5. Algorithm / Procedure
1. Create an HTML document.
2. Add an anchor element.
3. Specify the destination URL using `href`.
4. Insert an image using the `img` element.
5. Set the image path using `src`.
6. Add alternative text using `alt`.
7. Open the webpage in a browser.

## 6. Program / Queries / Commands
Refer to the existing `index.html` file for the complete HTML source code.

## 7. Input
A hyperlink URL and an image file path.

## 8. Output
A webpage containing a clickable hyperlink and an image.

Successfully added hyperlinks and images to an HTML webpage.
