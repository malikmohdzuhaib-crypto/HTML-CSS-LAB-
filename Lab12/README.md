## 1. Experiment Title
Box Model, Cards and Scrolling

## 2. Aim
To understand the CSS box model and create card layouts with scrolling sections.

## 3. Software / Tools Required
- HTML
- CSS
- Visual Studio Code
- Web Browser

## 4. Theory
The CSS box model describes how elements are displayed using content, padding, border and margin. The `box-sizing` property controls how element dimensions are calculated. The `overflow` property manages content that exceeds an element's available space.

## 5. Algorithm / Procedure
1. Create an HTML document.
2. Add content containers or cards.
3. Apply content dimensions.
4. Set padding, border and margin.
5. Use the `box-sizing` property.
6. Create a scrolling section using the `overflow` property.
7. Open the webpage in a browser.
