Flexbox Layouts

## 2. Aim
To create webpage layouts using CSS Flexbox.

## 3. Software / Tools Required
- HTML
- CSS

- Web Browser

## 4. Theory
CSS Flexbox is a one-dimensional layout system used to arrange elements in rows or columns. It provides properties such as `display: flex`, `justify-content`, `align-items`, `flex-wrap`, `gap` and `flex-direction` to control alignment and spacing.

## 5. Algorithm / Procedure
1. Create an HTML document.
2. Add a container and child elements.
3. Set the container's display property to `flex`.
4. Apply `justify-content` and `align-items`.
5. Set the flex direction and gap.
6. Use `flex-wrap` where required.
7. Open the webpage in a browser and observe the layout.
