# EXPERIMENT NO. 02

## 1. Experiment Title
Pushing and Cloning a Repository

## 2. Aim
To understand how to clone a Git repository and push local changes to a remote repository.

## 3. Software / Tools Required
- Git
- GitHub account
- Git Bash / Command Prompt
- Visual Studio Code

## 4. Theory
Git is a distributed version control system. Cloning creates a local copy of a remote repository, while pushing uploads local commits to the remote repository.

**Concepts:** Git clone, add, commit, push and pull.

## 5. Algorithm / Procedure
1. Open the GitHub repository.
2. Copy its repository URL.
3. Clone it using `git clone`.
4. Make changes to project files.
5. Stage and commit the changes.
6. Push the commit to GitHub.
7. Use `git pull` to fetch and integrate remote changes.

## 6. Program / Queries / Commands
```bash
git clone <repository-url>
git add .
git commit -m "Update files"
git push origin main
git pull origin main
```
Refer to the existing project files for the webpage code.

## 7. Input
A GitHub repository URL and modified project files.

## 8. Output
A webpage displaying Git push and clone commands.

Successfully learned how to clone a repository and push changes to GitHub.
