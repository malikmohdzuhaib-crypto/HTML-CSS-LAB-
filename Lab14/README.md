## 4. Theory
CSS Grid is a two-dimensional layout system used to arrange webpage elements in rows and columns. Properties such as `display: grid`, `grid-template-columns`, `grid-template-rows`, `grid-column`, `grid-row` and `gap` help control the layout.

## 5. Algorithm / Procedure
1. Create an HTML document.
2. Add a grid container.
3. Set its display property to `grid`.
4. Define columns and rows.
5. Place items in the required grid positions.
6. Apply gaps between grid items.
7. Open the webpage in a browser.
