## 1. Experiment Title
Units and CSS Variables

## 2. Aim
To understand CSS measurement units and use CSS variables in webpage styling.

## 3. Software / Tools Required
- HTML
- CSS
- Visual Studio Code
- Web Browser

## 4. Theory
CSS provides different units to define sizes and dimensions. Common units include `px`, `%`, `em`, `rem` and `vh`. CSS custom properties, also called CSS variables, store reusable values and are commonly declared inside the `:root` selector.

## 5. Algorithm / Procedure
1. Create an HTML document and CSS file.
2. Link the stylesheet to the HTML file.
3. Apply pixel and percentage units.
4. Use `em`, `rem` and `vh` where appropriate.
5. Declare CSS variables inside `:root`.
6. Use the variables in CSS properties.
7. Open the webpage in a browser.
