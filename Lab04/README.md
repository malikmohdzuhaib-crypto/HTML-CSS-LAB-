## 1. Experiment Title
Divs, Attributes and a Small Fix

## 2. Aim
To understand HTML div elements and attributes and apply CSS styling to webpage elements.

## 3. Software / Tools Required
- HTML
- CSS
- Visual Studio Code
- Web Browser

## 4. Theory
The HTML `div` element is a block-level container used to group elements. Attributes provide additional information about HTML elements. Common attributes include `class`, `id` and `title`. CSS is used to style these elements.

## 5. Algorithm / Procedure
1. Create an HTML document.
2. Add a `div` element.
3. Assign suitable class and ID attributes.
4. Add content inside the div.
5. Apply CSS styling using selectors.
6. Save the files and open the webpage in a browser.

Refer to the existing `index.html` and `style.css` files for the complete source code.
