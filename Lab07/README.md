# HTML & CSS Development Lab (BCS554)

# EXPERIMENT NO. 07

## 1. Experiment Title
About Me Page

## 2. Aim
To create a personal profile webpage using HTML and CSS.

## 3. Software / Tools Required
- HTML
- CSS
- Visual Studio Code
- Web Browser
- Image file

## 4. Theory
HTML provides the structure of a personal profile webpage using headings, paragraphs, images and lists. CSS controls its appearance, including colors, fonts, spacing and layout.

## 5. Algorithm / Procedure
1. Create an HTML document.
2. Add a heading for the profile.
3. Insert an image.
4. Add personal introduction text.
5. Include relevant information using lists.
6. Create CSS rules to style the webpage.
7. Open the webpage in a browser.

## 6. Program / Queries / Commands
Refer to the existing `index.html` and `style.css` files for the complete source code.

## 7. Input
Profile text, image and other relevant information.

## 8. Output
A personal profile webpage designed using HTML and CSS.

## 9. Result
Successfully created a personal profile webpage using HTML and CSS.
